# Dojo-1

A 2D action-adventure game built with Godot Engine, where players embark on an epic journey through medieval landscapes filled with formidable foes.

## Features

- **Dynamic Combat System**: Engage in thrilling battles with knights and skeletons using a variety of attacks, dodges, and special moves.
- **Rich Character Animations**: Experience fluid animations for the player character, including idle, running, jumping, attacking, rolling, and more.
- **Enemy Variety**: Face off against armored knights and undead skeletons, each with their own attack patterns and behaviors.
- **State Machine Architecture**: Built with a robust state machine system for smooth character transitions and AI logic.
- **Custom Input Mapping**: Intuitive controls for responsive gameplay.

## Assets

The game features hand-crafted pixel art sprites and animations, including:
- Player character with multiple action states
- Knight enemy with combat animations
- Skeleton enemy with undead behaviors
- Terrain tilesets and background layers
- Sound effects and audio management

## Getting Started

This project is developed using Godot 4.6.1. To run the game:

1. Clone the repository
2. Open the project in Godot Engine
3. Run the main scene or test_scene.tscn

## Development

The game is structured with modular scripts and scenes, making it easy to extend and modify. Key components include:
- Player controller with state-based movement
- Enemy AI using callable state machines
- Input handling system
- Scene management for levels and environments

Feel free to contribute, report issues, or suggest improvements!
